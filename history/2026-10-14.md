### 📊 Technical Changes
- **Approval Lock & Editable Documents (`validate_documents_editable`):**
  - Added `validate_documents_editable(status, code)` raising HTTP 409 Conflict when `status == STATUS_DUAL_APPROVED` or `_status_rank(status) >= _status_rank(STATUS_DUAL_APPROVED)`.
  - Enforced in `update_cargo_shipping_service` whenever `containers_loading_data`, `lcl_tracking_data`, or `shipment_type` is sent in the update payload.
  - Enforced at entry in `update_container_loading_tracking_service` and `update_lcl_loading_tracking_service`.
  - Non-container updates (e.g. `notes`, `crd_date`, `courier_tracking_data`) continue to succeed without false-positive 409 rejections.
- **Level 1 Approval Reset on Changes (Q5 Decision):**
  - When a record is before Dual Approved and `level1_approval_status == 'Approved'`:
    - In `update_cargo_shipping_service`, if `shipment_type` changed or `containers_or_seals_changed(existing, incoming)` is True: resets `level1_approval_status`, `level2_approval_status`, and `dual_approval_status` to `"Pending"` and appends an audit note to `level1_notes`.
    - In `update_container_loading_tracking_service`, if `payload.seal_no` is modified: resets `level1_approval_status`, `level2_approval_status`, and `dual_approval_status` to `"Pending"` and appends an audit note to `level1_notes`.
    - Idempotent re-sends with unchanged containers and seals leave Level 1 approval intact.
- **CargoX Rule Per Shipment Type (BE45-F13):**
  - In `execute_cargox_checklist_service`, "Bill of Lading (BL) & Container List Match" rule evaluates according to `record.shipment_type`:
    - **Air:** Passes unconditionally (`passed=True`) with details `"NOT_APPLICABLE"`.
    - **LCL:** Evaluates `bool(lcl_tracking_data.get("port_gate_in_at"))` (`passed=True` with `"LCL CFS consolidation gated in at port."` if gated in; `passed=False` with `"LCL port gate-in date is missing."` if missing).
    - **FCL:** Requires non-empty containers list and every container to have a non-empty `seal_no`.
- **Booking Link Validation (BE45-F29):**
  - In `validate_booking_link(db, booking_id, import_file_id)`: validates that `ShipmentBooking` exists, is active (`is_active == True`), and belongs to the same `import_file_id`.
  - Raises HTTP 422 with detail `"الحجز لا يخص نفس ملف الاستيراد"` if any check fails.
  - Enforced in both `create_cargo_shipping_service` and `update_cargo_shipping_service`.
