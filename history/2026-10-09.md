## 📝 Completed Task: Never post demurrage to a default import file (FE05-T01)

### 📌 Overview
- **Task Code:** FE05-T01 (Finding F05-01 / F05-21)
- **Severity:** BLOCKER
- **Description:** Fixed critical bug where demurrage and container detention fines could be posted to import file #1 by default when the tracking had no linked file (`importFileId: item.importFileId ?? 1`).

### 📊 Technical Changes
- **demurrage_detention_screen.dart**:
  - Removed `?? 1` fallback in `_handlePushToSettlement`.
  - Added guard: if `item.importFileId == null`, displays a warning SnackBar (`demPushNeedsLinkedFile`) and halts without calling the API.
  - Added confirmation step via `DemurragePushToSettlementConfirmDialog.show`: displays file code, exchange rate, total demurrage FX, total detention FX, total storage EGP, and total cost EGP.
  - Passes `importFileId: item.importFileId` only when confirmed.
- **demurrage_tracking_card.dart**:
  - In `DemurrageTrackingCard`, when `item.importFileId == null`, the push button is disabled (`onPressed: null`) and displays a tooltip (`demPushNeedsLinkedFile`: "Cannot push to financial settlement: link an import file first" / "لا يمكن الترحيل للتسوية المالية: يجب ربط ملف استيراد أولاً").
- **demurrage_form_dialogs.dart**:
  - Created `DemurragePushToSettlementConfirmDialog`: uses `CcStageDialogShell`, displays import file chip, confirmation notice, and breakdown facts (`CcFact`, `CcFieldRow`, `CcFormSection`).
- **demurrage_provider.dart**:
  - In `pushToSettlement`, `import_file_id` is only included in the POST payload when `importFileId != null` (`if (importFileId != null) payload['import_file_id'] = importFileId`).
- **Localization**:
  - Added 10 new localization keys to `app_localizations.dart`, `app_localizations_ar.dart`, and `app_localizations_en.dart`: `demPushNeedsLinkedFile`, `demPushConfirmTitle`, `demPushConfirmMessage`, `demPushConfirmFileCode`, `demPushConfirmDemurrageFx`, `demPushConfirmDetentionFx`, `demPushConfirmStorageEgp`, `demPushConfirmRate`, `demPushConfirmTotalEgp`, `demPushConfirmBtn`.
  - Arabic strings strictly contain zero Latin characters.
