### 📊 Technical Changes
- **RBAC**: All GET routes require `lifecycle_board.view`; stage advance, sync, skip, set-active, and pending-reference require `lifecycle_board.advance`.
- **Acting User**: The completed activity's `assigned_user` is strictly populated from `actor.username`, completely ignoring any payload field or header spoofing.
- **State Guards**: Reject advancing inactive or closed/archived/on-hold files with 409 `LC_FILE_NOT_ACTIVE`. Reject unknown files with 404 `LC_FILE_NOT_FOUND` with 0 orphan DB rows. Reject completing `STEP_21` via HTTP (reserved for file closure). Reject completing steps not currently In-Progress or Pending Reference with 409 `LC_STEP_NOT_ACTIVE`.
- **Admin Privilege**: `auto_complete_prior` is honored strictly for ADMIN users; non-admin users cannot auto-complete prior stages.
