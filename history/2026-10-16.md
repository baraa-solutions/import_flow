### 📊 Technical Changes
- `validate_demurrage_dates`: Added `require_gate_out_for_return: bool = True` (default `True`). Raises 422 if `empty_return_date` is set without `gate_out_date`.
- `simulate_demurrage_and_detention`: Sets `require_gate_out_for_return=False` to safely process legacy records, but clamps `demurrage_end_date` and `storage_end_date` to `empty_return_date` if it precedes `calc_date`.
- `record_empty_container_return_service`: Scans all target containers to ensure each container or the tracking session has a recorded `gate_out_date`, raising 422 with the list of failing containers if any is missing.
- Flutter UI: Shows snackbar and prevents submitting empty return without gate-out.
