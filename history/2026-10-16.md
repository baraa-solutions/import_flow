## 📝 2026-10-16 - Completed Task: One active insurance certificate per file (BE45-T05)

### 📌 Overview
- **Task Code:** `BE45-T05`
- **Severity:** CRITICAL (BE45-F05)
- **Description:** Enforce strict uniqueness of active cargo insurance certificates per import file (`import_file_id`). Prevents multiple active draft certificates from inflating landed cost calculations in financial settlement. Creating a second active certificate for the same file raises HTTP 409 Conflict. Creation is allowed once the existing certificate is soft-deleted or marked `CANCELLED`. Standalone certificates without an import file remain unconstrained.
