## 📝 2026-10-16 - Completed Task: Tracking currency = tariff currency (ACC3-T05)

### 📌 Overview
- **Task Code:** `ACC3-T05`
- **Severity:** CRITICAL (ACC3-F05)
- **Description:** Tracking session currency must strictly match the carrier tariff currency (or default tariff currency when no carrier policy matches). Prevents converting foreign carrier tariffs in incorrect currencies (e.g. converting a EUR tariff using USD exchange rates). `DemurrageTrackingCreate.currency` is now optional; when omitted, it inherits the policy currency. When sent with a mismatching currency, it raises HTTP 422. Flutter tracking create dialog stops sending hardcoded USD, and policy create dialog provides a searchable currency picker.

### 📊 Technical Changes
- **Tariff & Tracking Currency Alignment:**
  - `Tariff` dataclass carries `currency: str = "USD"`.
  - When creating a tracking, `_resolve_tariff` provides `tariff.currency`.
  - If `req.currency` is omitted / `None`, tracking inherits `tariff.currency`.
  - If `req.currency` is passed and differs from `tariff.currency`, HTTP 422 is raised.
  - FX rate is resolved for the actual `tariff.currency` at the discharge date.
- **Recalculation Integrity:**
  - `_tracking_tariff` callers retain `tracking.currency`. If the carrier policy's currency changed after tracking creation, a warning is logged and the tracking currency is preserved to avoid silent currency re-labelling.
- **Worked Example Verified:**
  - EUR policy (100 EUR/day, 14 free days), discharge 2026-08-01, gate-out 2026-08-20 (5 overdue days) -> 500 EUR demurrage.
  - EUR rate 54 on discharge date -> `currency == "EUR"`, `exchange_rate == 54.0`, `total_cost_egp == 27000.00`.
