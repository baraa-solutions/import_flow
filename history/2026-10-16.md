### 📊 Technical Changes
- **Validation of Gate-Out before Empty Return**:
  - `validate_demurrage_dates` raises HTTP 422 `"لا يمكن تسجيل إعادة الحاوية الفارغة بدون تاريخ خروجها من الميناء (Gate-Out)."` if `empty_return_date` is provided without `gate_out_date`.
- **Defensive Capping in Demurrage / Port Storage Engine**:
  - `demurrage_end_date = req.gate_out_date or calc_date` capped at `empty_return_date` if `empty_return_date < demurrage_end_date`.
  - `storage_end_date = req.gate_out_date or calc_date` capped at `empty_return_date` if `empty_return_date < storage_end_date`.
  - Prevents accrual of demurrage or storage past the return date on legacy rows or un-gated returns.
- **Batch EIR Gate-Out Verification**:
  - `record_empty_container_return_service` aggregates all target containers lacking a gate-out date and reports them in a single HTTP 422 message.
