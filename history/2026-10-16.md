### 📊 Technical Changes
- `free_demurrage_days` now defaults to `None` in `ShipmentBooking` Python model, so newly created bookings without agreed free days persist `NULL` in the database.
- Schema validation enforces `ge=0` on `free_demurrage_days` (rejecting negative numbers with 422).
- Omitting `free_demurrage_days` on `/confirm` does not overwrite or wipe previously agreed free days.
- `_agreed_tariff` uses `is not None` rather than truthy checks, distinguishing 0 agreed days from unagreed (None), allowing policies to provide free days when None and applying 0 when 0 was agreed.
- Flutter UI allows empty free days field on confirm and form dialogs, serializing `null` or omitting the key.
