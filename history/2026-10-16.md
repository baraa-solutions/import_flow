## 📝 2026-10-16 - BE45-T05: One Active Insurance Certificate Per Import File

### 📌 Overview
- **Task Executed:** `BE45-T05`: One active insurance certificate per import file (`modules/cargo_insurance`)
- **Severity:** CRITICAL (F05)
- **Goal:** Prevent creating multiple active certificates for the same import file, avoiding double-counting of insurance premiums in financial settlement landed cost.

### 📁 Files Changed
- `modules/cargo_insurance/repository.py`: Added `get_active_for_file(import_file_id)` returning the active certificate with `status != "CANCELLED"` and `is_active == True`.
- `modules/cargo_insurance/validators.py`: Added `validate_no_active_certificate_for_file(existing)` returning HTTP 409 Conflict with detail message `يوجد بالفعل وثيقة تأمين نشطة لهذا الملف (<code>)`.
- `modules/cargo_insurance/service.py`: Enforced validation check in `create_certificate` when `import_file_id` is provided.
- `tests/unit/test_be45_insurance_unique.py`: 5 comprehensive unit tests covering 409 duplicate prevention, soft-deleted certificate replacement, cancelled certificate replacement, multi-file independence, and the financial settlement money example.
- `docs/plans/review-shared-needs.md`: Appended note regarding `financial_settlement/service.py:1431` to filter on `status == 'ISSUED'` certificates.
- `docs/plans/backend-review/TASKS.md`: Updated BE45-T05 status to `done (fix/be45-t05-insurance-certificate-unique)`.

### 📊 Technical Changes
- Enforced single active insurance certificate per `import_file_id` at the application layer.
- Allowed creation of a new certificate if the earlier certificate was soft-deleted (`is_active == False`) or cancelled (`status == "CANCELLED"`).
- Retained support for unlinked certificates (`import_file_id == None`).
