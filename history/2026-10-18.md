# 2026-10-18 Task History

## BEX-T14: Paginated Endpoints for the Largest Tables and Remaining Route Permissions

### 🎯 Objective
Resolve MAJOR findings `BEX-F30`, `BEX-F31`, and MINOR `BEX-F42` from `docs/plans/backend-review/be-cross-review.md`:
1. Provide standard paginated endpoints (`Page[T]` envelope + `X-Total-Count` header, bounds `page>=1`, `page_size<=200`, deterministic primary key sort tie-breaker, sort whitelist, text search filter `q`, backward-compatible with legacy list routes) for the largest tables in the system:
   - `modules/smart_tasks` (`GET /api/v1/smart-tasks/paginated`)
   - `modules/audit_logs` (`GET /api/v1/audit-logs/paginated` and `GET /api/v1/audit-logs/{entity_type}/{entity_id}/paginated`)
   - `modules/notifications` (`GET /api/v1/notifications/paginated`)
   - `modules/transport_locations` (`GET /api/v1/transport-locations/paginated`)
   - `modules/suppliers` (`GET /api/v1/suppliers/paginated`)
   - `modules/import_companies` (`GET /api/v1/import-companies/paginated`)
   - `modules/external_service_providers` (`GET /api/v1/external-service-providers/paginated`)
2. Enforce the cross-cutting route permission matrix:
   - `smart_tasks`: GET -> `import_files.view`; writes/state-transitions -> `import_files.edit`; `sync-all-active-files` -> `require_admin`.
   - `notifications`: GET/summary/read/mark-all-read -> authenticated user (`get_current_user`); POST create & `trigger-expiry-check` -> `require_admin`.
   - `experience_guide`: GET -> `import_files.view`; writes/recalculate -> `import_files.edit`; promote/reject -> `require_manager_or_admin` + `import_files.edit`.
   - `smart_email_listener`: `GET /logs` and `GET /logs/{email_id}` -> `import_files.view`.
   - `system_observability`: `alerts/evaluate` with `force=true` -> restricted to `is_admin_user` (returns 403 Forbidden for non-admins); `recent-traffic` -> query bound `Query(50, ge=1, le=500)`.
