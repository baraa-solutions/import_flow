# 2026-10-28 — CBM Calculator & Shipping Scenarios Enhancement: Road LDM, Non-Stackable LCL Loss of Height, Ocean Revenue Ton, and Pallet Presets

- Support for Road Freight / Trucking Loading Meters (**LDM**) using the 2.40m standard trailer width standard.
- Support for Ocean LCL Non-Stackable Cargo Rule calculating **Chargeable / Billed CBM** using the standard 2.20m container clearance height factor (loss of height compensation).
- Support for Ocean Freight Weight or Measure (**W/M**) and **Revenue Ton (RT)** calculation ($1\text{ CBM} \equiv 1,000\text{ kg}$).
