# إدارة المهام الذكية ومحرك التذكيرات (Smart Tasks & Alerts)
![](../screenshots/55-smart-tasks-main.png)

> التصوير اتعمل على **Flutter Web (release)**. الصورة الرئيسية اتاخدت والجدول لسه بيحمّل (skeleton) مع إن العدّاد بيقول "5 سجل". الصفوف الخمسة باينة ورا الـ dialog في صورة `55-smart-tasks-dialog-add.png`.

## الغرض والمستخدمين والمرحلة (BP/MD)
- **الغرض:** قائمة مهام وتذكيرات تشغيلية (يدوية أو بيولّدها النظام)، ممكن تتربط بملف استيراد، ولكل مهمة أولوية ونوع تذكير وتاريخ استحقاق وتاريخ تنبيه. ومن نفس الشاشة بتفتح **المستمع الذكي لإيميلات الخطوط الملاحية وإشعارات الوصول**.
- **المستخدمين:** كل فريق التشغيل.
- **المرحلة:** أداة دعم لكل المراحل. مالهاش BP/MD code في `inventory.json`.

## طريقة الوصول والصلاحية
- **Sidebar:** "لوحة القيادة والتقارير والرقابة" ← "المهام والتنبيهات الذكية" (index 40). وكمان من كارت "المهام المرتبطة" في لوحة التحكم (`operational_dashboard_screen.dart:1232`).
- **Scaffold:** `Scaffold` + `PageHeader` (عنوان وعنوان فرعي و"العودة للداش بورد").
- **الصلاحية:** أي مستخدم مسجّل (`modules/smart_tasks/router.py:21`). إعدادات البريد ADMIN بس.

### الجداول
جدول `EnterpriseColumn` (`smart_tasks_screen.dart:180` وما بعده):
| العمود | المعنى |
|---|---|
| ☐ | اختيار للعمليات الجماعية |
| كود المهمة | TSK-YYYY-NNNN (بيتنسخ بالضغط) |
| النوع | يدوي / النظام |
| العنوان | العنوان والوصف |
| الشحنة | الاسم التجاري (كود الملف) |
| الأولوية | Badge ملوّن (منخفضة / متوسطة / عالية / حرجة) |
| محرك التذكير | نوع التذكير |
| تاريخ الاستحقاق | YYYY-MM-DD |
| الحالة | قيد الانتظار / مكتملة… |
| الإجراءات | زي ما هو موضّح فوق |

- **الفلاتر:** النوع، والأولوية، والحالة، والبحث، وبحث فوري جوه الجدول.
- **هيدر الجدول:** عنوان "جدول المهام الذكية والتنبيهات التشغيلية" وشارة العدد ("5 سجل")، وتحت الجدول "عرض 1 - 5 من إجمالي 5" واختيار "الصفوف بالصفحة". وفي آخر شريط الأدوات 3 أيقونات: إعادة ضبط الفلاتر، وتحديث حي، ونسخ جدول نصوص.
- **الترتيب:** كل الأعمدة قابلة للترتيب (أسهم ⇅ في الهيدر). والـ pagination: 25 صف في الصفحة.
