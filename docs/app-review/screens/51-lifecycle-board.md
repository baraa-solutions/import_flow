# لوحة تتبع ومتابعة مراحل الشحنات التفاعلية (Lifecycle Operations Board)
![](../screenshots/51-lifecycle-board-main.png)

> التصوير اتعمل على **Flutter Web (release)** على قاعدة بيانات scratch فيها 6 ملفات استيراد في مراحل مختلفة. الصورة بتوضح وضع "عرض مراحل العمليات (6 مراحل)". وضع "رادار التتبع اللوجستي الحي" ما اتصورش.

## الغرض والمستخدمين والمرحلة (BP/MD)
- **الغرض:** لوحة Kanban بتعرض دورة حياة الشحنة في **6 مراحل كبرى / 25 خطوة تشغيلية**، ومع كل خطوة عدد الشحنات اللي واقفة عندها. لما تضغط على مرحلة أو خطوة، الجدول اللي تحت بيتفلتر. ومن عمود الإجراءات تقدر تقدّم الخطوة، أو تتخطاها، أو توقف الشحنة، أو ترجّعها (`StepActionDialog`).
- **الوضع التاني (رادار التتبع اللوجستي الحي):** جدول فيه السفينة والبوليصة، والـ ETA والعد التنازلي، وجاهزية المستندات، وخطر الأرضيات، وحالة العينات، وإجراءات سريعة (`lifecycle_board_screen.dart:422` و `:786`).
- **المستخدمين:** مدير العمليات، ومسؤولي الاستيراد والتخليص.
- **المرحلة:** شاشة متابعة لكل المراحل (Type C). من `inventory.json`: **BP-001** لحد **BP-040**.

## طريقة الوصول والصلاحية
- **Sidebar:** "لوحة القيادة والتقارير والرقابة" ← "لوحة تتبع ومراحل الشحنات التفاعلية" (index 48). وكمان من زرار "فتح لوحة المراحل التفاعلية" في لوحة التحكم.
- **Scaffold:** `Scaffold` + `PageHeader`، وفيه تبديل الوضع، وتحديث، و"العودة للداش بورد".
- **الصلاحية:** الـ router محمي بـ `Depends(get_current_user)` (`modules/lifecycle_board/router.py:29-33`). التخطي عليه فحص دور في الـ service (MANAGER/GENERAL_MANAGER/ADMIN، أو الأدوار المسموحة في إعداد الخطوة، `modules/lifecycle_board/service.py:1054`). التقديم (`advance`) و `set-active` مالهمش أي فحص دور.
- **التحديث التلقائي:** polling بفترة بتتغير حسب الخطر: 20 ثانية لو فيه حاويات عالية الخطر في الأرضيات (`highRiskDemurrageCount > 0`)، وإلا 60 ثانية (`live_polling_provider.dart:39-42`).

## مكونات الشاشة

- **سطر المستويات:** فوق الكروت عنوان "المستويات الستة الكبرى — اضغط على أي مرحلة لعرض وتحديث شحناتها بالجدول أدناه"، وجنبه شارة "إجمالي الشحنات: 6 ملف (6 مرحلة)". كل كارت مرحلة فيه رقم إجمالي في الهيدر، وكل خطوة جواه ليها radio ورقم؛ الخطوة اللي عليها شحنات بتتلوّن بلون المرحلة.

### الجداول
**جدول الشحنات (وضع المراحل)** (`lifecycle_board_screen.dart:1572-1582`):
| العمود | المعنى |
|---|---|
| اسم الشحنة | كود الملف (FILE-…) وتحته شارة كود الاستيراد (IMP-…) |
| المسار السابق / الحالي / التالي | اسم الخطوة السابقة، والحالية (Badge ملوّن)، والتالية |
| الشركة المستوردة | عربي / إنجليزي |
| المورد الأجنبي | اسم المورد |
| أمر الشراء | PO-… |
| نوع الشحن والشرط | مثلاً `Sea FCL \| FOB` |
| القيمة التقديرية | القيمة + العملة |
| الملاحظات والأنشطة | مثلاً "نقطة البداية المحددة للشحنة: STEP_01" |
| الإجراءات والتقدم | زرار بيفتح `StepActionDialog` (مش ظاهر في الصورة، لازم تعمل scroll أفقي) |

- **الفلاتر:** المرحلة أو الخطوة من الكروت، والبحث النصي. العدّاد "6 شحنة".
- **الترتيب:** حسب ترتيب الباك إند.

**جدول الرادار:** السفينة والبوليصة، والناقل، والـ ETA والعد التنازلي، وجاهزية المستندات، وخطر الأرضيات، وحالة العينات، وإجراءات سريعة.

### التابات
مفيش TabBar. فيه زرارين لتبديل الوضع (Kanban / الرادار) في الهيدر.

### الـ Dialogs
`StepActionDialog` (`frontend/lib/features/lifecycle_board/widgets/step_action_dialog.dart`): تقديم الخطوة مع بارامترات حسب الخطوة، وتخطي بسبب إلزامي (validator `l10n.skipReasonRequired`، `step_action_dialog.dart:207`)، وإيقاف بسبب، واستئناف. **ما اتصورش**: مفيش زرار إضافة، والـ harness ما فتحش dialog الإجراءات.

### التصدير والطباعة
TSV و Excel و PDF أفقي ونسخ للحافظة، للـ Kanban وللرادار. الملفات بتتحفظ عن طريق `FileSaveHelper` (`lifecycle_board_export_service.dart`)، والـ PDF عن طريق `Printing.layoutPdf`.
