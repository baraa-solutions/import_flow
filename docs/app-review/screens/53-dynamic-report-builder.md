# مُنشئ التقارير الديناميكية والمخصصة (Dynamic Report Builder)
![](../screenshots/53-dynamic-report-builder-main.png)

> التصوير اتعمل على **Flutter Web (release)** على قاعدة scratch فيها 6 ملفات استيراد. الجدول ظهر فاضي بسبب فلتر القالب الافتراضي (راجع أول ملاحظة).

## الغرض والمستخدمين والمرحلة (BP/MD)
- **الغرض:** تقرير جدولي مرن لملفات الاستيراد. بتختار قالب جاهز أو بتختار الأعمدة بنفسك من 8 فئات (ملف/مشروع، أمر شراء، شحن ولوجستيات، جمارك ونافذة، بنوك وسويفت، طرود و CBM، أعمدة ECO Radar، أعمدة SCAS Tracker)، وبعدين بتفلتر وتصدّر.
  - **قالب شركة إيكو (ECO Radar):** 15 عمود لتتبع المستندات والـ milestones.
  - **قالب شركة سكاس (SCAS Tracker):** 16 عمود للتتبع التشغيلي والسويفت.
  - **تخصيص حر (ديناميكي):** الأعمدة اللي اخترتها.
- **المستخدمين:** الإدارة، وخدمة العملاء (تقارير للعملاء إيكو وسكاس)، ومسؤولي التشغيل.
- **المرحلة:** تقارير. مالهاش BP/MD code في `inventory.json`.

## طريقة الوصول والصلاحية
- **Sidebar:** "لوحة القيادة والتقارير والرقابة" ← "مُنشئ التقارير المخصصة" (index 41).
- **Scaffold:** `Scaffold` بهيدر مخصص (مش `PageHeader`) فيه العنوان، و chip "آخر تحديث"، وتحديث، و"العودة للداش بورد".
- **الصلاحية:** أي مستخدم مسجّل (`/import-files` و `/projects` و `/purchase-orders` محمية بـ `get_current_user`).
- **تحميل البيانات:** `initState` بيجيب ملفات الاستيراد والمشاريع وأوامر الشراء (`dynamic_report_builder_screen.dart:101-125`).

### الجداول
- **جدول التقرير:** `DataTable` أعمدته بتتغير حسب القالب (`:1200` وما بعده)، وفيه أعمدة مميزة بلون حسب القالب.
- **الفلاتر:** القالب، والبحث، ووسيلة النقل، والأولوية. وفيه `_filterStatus` في الكود بس ثابت على `'All'` ومالوش عنصر في الواجهة (`:96`).
- **الترتيب:** حسب ترتيب البيانات، ومفيش ترتيب بالعمود.
