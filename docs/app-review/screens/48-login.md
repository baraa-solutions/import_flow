# تسجيل الدخول (Login)
![](../screenshots/48-login-main.png)

> التصوير اتعمل على **Flutter Web (release)** مش Windows desktop، لأن Visual Studio مش متسطّب على جهاز المراجعة. الباك إند شغال على قاعدة بيانات scratch.

## الغرض والمستخدمين والمرحلة (BP/MD)
- **الغرض:** بوابة الدخول للنظام. المستخدم بيكتب اسم المستخدم (أو الإيميل) وكلمة المرور، والتطبيق بياخد JWT من الباك إند وبيفتح الواجهة الرئيسية.
- **المستخدمين:** كل مستخدمي النظام (ADMIN / MANAGER / OPERATOR).
- **المرحلة:** مالهاش مرحلة في دورة الاستيراد، ومالهاش BP/MD code. دي شاشة بنية تحتية.

## طريقة الوصول والصلاحية
- بتظهر تلقائياً من `AuthGate` (`main.dart:327` حسب `inventory.json`) طول ما مفيش token صالح.
- **الصلاحية:** عامة (Public). `POST /api/v1/auth/login` و `POST /api/v1/auth/refresh` في الـ allow-list، وأي route تاني محتاج JWT.
- الـ login عليه rate limit (`login_limiter.check_rate_limit` في `modules/auth/router.py:75`).
- الـ token بيتخزن في `flutter_secure_storage` (`frontend/lib/features/auth/providers/auth_provider.dart:5` و `:44`). ولو الـ token انتهى وقت الإقلاع، بيحاول refresh صامت (`auth_provider.dart:93-95`).

## مكونات الشاشة

- **الهيدر:** أيقونة الشاحنة، والعنوان "سرور للخدمات اللوجستية"، والوصف "منظومة سرور لإدارة سلاسل الإمداد والاستيراد والتخليص الجمركي". وتحت زرار الدخول عنوان قسم "الدخول السريع بحسابات النظام التجريبية:" (`elements/48-login-main.json` → `visible_texts`).
